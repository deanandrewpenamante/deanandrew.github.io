# Dean Peñamante — Portfolio Website

A responsive personal portfolio starter built with HTML, CSS, and a small JavaScript file.

## Files
- `index.html` — portfolio content and sections
- `style.css` — layout, colors, typography, and mobile responsiveness
- `script.js` — automatically updates the footer year

## Customize before publishing
1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com` with your email.
3. Replace `YOUR_USERNAME` with your GitHub username.
4. Replace the sample project links with your actual repository URLs.
5. Update your skills and project descriptions so they accurately reflect your experience.

## Publish with GitHub Pages
1. Create a public GitHub repository named `YOUR_USERNAME.github.io` (replace with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for deployment, then visit `https://YOUR_USERNAME.github.io`.

Note: GitHub Pages hosts static sites. This portfolio works because it uses HTML, CSS, and client-side JavaScript. It does not run PHP/Laravel backend code.
